# HireHub — Recruitment Management Platform

## About the Project
HireHub is a responsive recruitment management website designed to simplify the hiring process for companies and job seekers. It provides an interactive platform for exploring job opportunities and managing recruitment activities.

## Features
- Job listings and job search
- Search and category filtering
- Detailed job information
- Online job application form
- Applicant dashboard
- Application status tracking
- Interview scheduling
- Recruitment analytics with charts and progress bars
- Job posting functionality
- Responsive design for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage

## Project Purpose
This project was developed to demonstrate frontend web development skills, responsive user interface design, and interactive recruitment management features.

## Note
This is a frontend demonstration project. Application and custom job data are stored in the browser's Local Storage. A backend database and real multi-user functionality are not currently implemented.
